Для сборки исходников и запуска из Rider нужен SDK 10.0.402; тест host runtime проверяет тот же Development-загрузчик и content root без открытия IDE. Расчёты с нативными DLL проверялись внутри Linux Docker, host-проверка выполняла startup обеих БД, `hello` и чтение справочника.
