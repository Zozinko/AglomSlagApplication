# REPO-02 · Проверка запуска с частной подсетью

Дата: 31.10.2026. Среда: Debian 13, Docker 29.9.2, Compose 5.6.1.

## Проверки конфигурации

Из корня репозитория успешно выполнены обе команды, код завершения 0:

```bash
docker compose --env-file Soft/.env -f Soft/Docker-compose.yml config --quiet
docker compose --env-file Soft/.env -f Soft/Docker-compose.yml -f Soft/compose.private-network.yml config --quiet
```

Основной файл сохранён без изменений. Дополнительный файл задаёт только подсеть существующей сети; настройки сервисов, порты и volume остаются в основном файле. Обычный вариант проверен на корректность конфигурации, полный запуск проверен с дополнительным файлом.

## Реальный запуск

Перед запуском пользовательских сетей и запущенных контейнеров не было. Инструмент туннелирования трафика активен: в таблице маршрутов присутствуют маршруты через `tun2`. Физическая локальная сеть использует другой диапазон, `192.168.0.0/24`.

```bash
docker compose --env-file Soft/.env -f Soft/Docker-compose.yml -f Soft/compose.private-network.yml up -d --build
docker compose --env-file Soft/.env -f Soft/Docker-compose.yml -f Soft/compose.private-network.yml ps -a
docker network inspect soft_agloslag_network --format '{{range .IPAM.Config}}{{.Subnet}}{{end}}'
```

Сборка и запуск завершились с кодом 0. Фактическая подсеть `soft_agloslag_network` — `192.168.100.0/24`.

- `aglom_postgres`: работает, `healthy`.
- `aglom_migrator`: `Exited (0)`.
- `aglom_graphql_api`: работает, порт хоста 5000.
- `GET http://127.0.0.1:5000/graphql?sdl`: HTTP 200, в ответе есть `type Query`.
- `POST http://127.0.0.1:5000/graphql` с запросом `{ __typename }`: `data.__typename = Query`, ошибок GraphQL нет.

HTTP-проверки выполнены Python urllib напрямую, без HTTP-прокси окружения. Первая попытка открыть `/graphql` с настройками HTTP-клиента по умолчанию завершилась после перенаправления кодом 403; доступность браузерного редактора этим прогоном не подтверждена. Прямые проверки SDL и GraphQL прошли успешно.

Локальный журнал сборки и запуска: `logs/REPO-02-startup.log` (исключён из Git). Приложение оставлено работающим с дополнительной конфигурацией; volume БД сохранён.

## Документация и границы проверки

Проверены относительные ссылки изменённых документов и отчётов, `git diff --check`, состав изменений и исключение `.env` и журнала запуска из Git. Пользовательская правка `.gitignore` сохранена.

Полный набор API-тестов не запускался: прикладной код не менялся. Подсеть проверена на этой системе; отсутствие пересечений на других компьютерах не гарантируется. Ограничения доступа, заданные инструментом туннелирования, отдельная подсеть сама по себе не устраняет. Автоматическое пересоздание уже существующей сети не проверялось: в инструкции предусмотрено переключение через `down` без удаления volume.
