## Задача

Сохранить обычный запуск и добавить необязательную конфигурацию сети для систем с инструментом туннелирования трафика. Все настройки приложения продолжить читать из одного `Soft/.env`.

1. Прочитаны `arcitecture.md`, `docs/configuration.md`, правила ведения репозитория и TODO. Проверено исходное состояние Git: пользовательское изменение `.gitignore` сохранено.
2. В TODO добавлена задача REPO-02 с критериями проверки.
3. Добавлен `Soft/compose.private-network.yml`: только настройка IPAM подсети `192.168.100.0/24` существующей сети `agloslag_network`. Основной Compose-файл не изменялся.
