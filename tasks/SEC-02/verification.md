# SEC-02 — проверка

Дата: 26.10.2026. Реализация и тесты независимо прочитаны/проверены тимлидом перед запуском. Субагенты тесты не запускали; финальный общий прогон выполнен один раз, без ошибок и повторов.

JWT HS256 проверяется по подписи, issuer, audience, сроку действия и алгоритму. Login открыт, остальные Query и Mutation требуют JWT. В этом историческом этапе Production использовал HTTPS, а транспорты были закрыты; эти настройки позже убраны, см. [упрощение запуска](http-simplification.md). Проверены прежние 16 операций, ошибочные JWT, Login в общем запросе без записи до проверки входа, aliases/fragments, SDL/IDE/GET/WebSocket, ошибочная конфигурация и ограничение частоты по IP.
