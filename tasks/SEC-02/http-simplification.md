# Упрощение запуска HTTP

Дата: 26.10.2026. Уточнение пользователя после SEC-02/03/04 и OWN-01: подготовка — клонирование, настройка одного `.env`, один `docker compose up -d --build`, работа через `requests`.

Удалены обязательный HTTPS middleware, настройки/монтирование PFX, параметры TLS из `.env.example` и локального `.env`, созданные ранее локальные сертификаты, HTTPS-профиль IDE и TLS-подготовка тестов. HTTP используется в Production. Публичны страница GraphQL, SDL и introspection; `/` ведёт на `/graphql`. Все бизнес-поля, кроме Login, сохраняют JWT-аутентификацию, включая GET и смешанные документы. Права владельца, хеширование и refresh сохранены.

`DEMO_BOOTSTRAP=true` в обычном Compose автоматически создаёт аккаунты -1/-2 из `.env` после миграций. Дополнительная bootstrap-команда не требуется. Повторный запуск не сбрасывает существующие пароли и данные.
